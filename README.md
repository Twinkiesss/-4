# Лабораторная работа №4 — Метод k-ближайших соседей (k-NN)

Реализация k-NN с нуля на NumPy/Pandas для датасета Wine.

## Данные
Wine: 178 образцов, 13 химических признаков, 3 класса (59/71/48).

## Что делает код
- Предобработка: медианная импутация и z-score только по train (без утечки).
- Стратифицированное разбиение 75/25, seed=42.
- k-NN без sklearn: евклидово расстояние, голосование большинством.
- Две модели: случайные признаки (seed=42) и фиксированный набор
  (Alcohol, Flavanoids, Color intensity, Proline).
- Оценка при k = 1, 3, 5, 7, 10, 15; матрицы ошибок; график Accuracy vs k.

## Запуск
```bash
pip install -r requirements.txt
python knn_wine.py
